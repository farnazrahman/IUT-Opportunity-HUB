IUT Opportunity Hub — Presentation & Slide Breakdown
Welcome to the IUT Opportunity Hub project presentation summary. This repository contains the slide overview and team contribution details for SWE 4304: Software Project Lab I.
?? Slide Structure & Team Breakdown
Slide 1: Title Slide
* Content: Overview of the project title (IUT Opportunity Hub), course code (SWE 4304), and team members.
Slide 2: Introduction
* Content: Brief introduction to the platform — a centralized hub for the IUT community to discover academic and professional opportunities easily.
Slide 3: Motivation
* Content:
o The Beginning: Challenges finding research interests, faculty availability, and senior mentorship.
o The Realization: Establishing a unified platform to connect students, alumni, and faculty.
Slide 4: Problem Statement
* Content: 4 key core challenges:
1. Difficulty matching research interests with faculty/seniors.
2. Difficulty finding research collaborators with relevant skills.
3. Lack of a single platform for internships, jobs, and research.
4. Difficulty connecting with alumni studying or working abroad.
Slide 5: Target Stakeholders
* Content:
o Students: Search opportunities, track applications, request mentorship.
o Alumni: Share experience, guide students, post jobs/study opportunities.
o Faculty: Find research collaborators, manage incoming requests.
Slide 6: Key Features
* Content:
1. Opportunity Management (Browse, filter, apply, track)
2. Alumni & Mentorship (Profiles, connection requests)
3. Research Collaboration (Publish projects, request participation)
4. Recommendation System (Matching based on skills and background)
Slide 7: Process Flow
* Content: 5-step user lifecycle: Build Profile ? Discover ? Match ? Request / Apply ? Respond
Slide 8: Tools & Technology
* Content:
o Programming Language: Java
o IDE: IntelliJ IDEA
o Version Control: Git & GitHub
Slide 9: Project Timeline
* Content: Gantt chart outlining development phases across Weeks 2 to 14 (Current status: Week 4).
